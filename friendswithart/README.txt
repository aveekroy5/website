Friends With Art responsive landing page
==========================================
Pure HTML + CSS + JavaScript.

Files:
- index.html
- style.css
- script.js
- assets/

Open index.html directly in a browser.

Notes:
- The supplied logo is used as assets/logo.jpg.
- Product photography is cropped from the approved landing-page visual so the page is self-contained.
- Replace files in assets/ with original Instagram/product photos when you have permission/access to those originals.
- Cart/search are front-end demo interactions only; no backend/payment is connected.
